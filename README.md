# Biopython Practice Notebooks 🧬

A collection of Python notebooks built while learning bioinformatics programming.
Covers DNA/RNA sequence analysis, FASTA file handling, NCBI data retrieval, and data visualization.

## Topics Covered
- Biopython: Seq objects, transcription, translation, GC content, complement
- Biopython: FASTA files, SeqIO, SeqRecord, real NCBI sequences
- NumPy: array operations and calculations
- Pandas: DataFrames, filtering, groupby, missing data
- Matplotlib: bar charts, line charts, scatter plots

## Tools & Libraries
- Python 3
- Biopython
- NumPy
- Pandas
- Matplotlib

## Files
| File | Description |
|------|-------------|
| `biopython_learning.ipynb` | Seq objects, GC content, transcription, translation |
| `biopython_fasta.ipynb` | FASTA parsing, SeqIO, SeqRecord |
| `ncbi_analysis.ipynb` | Real NCBI gene data + Pandas + Matplotlib |
| `numpy_learning.ipynb` | NumPy arrays and operations |
| `pandas_learning.ipynb` | DataFrames and biological datasets |
| `matplotlib_learning.ipynb` | Data visualization with biology examples |
